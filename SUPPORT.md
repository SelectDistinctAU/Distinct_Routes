## FREQUENTLY ASKED QUESTIONS

### Q: Why won't my route calculate?

**A:** Common causes:
- Invalid start/end coordinates (check input)
- BBBike API unavailable (wait 30 seconds and retry)
- No internet connection (enable WiFi/mobile data)
- GPS accuracy poor (>10m) — try manual entry

### Q: How do I export routes?

**A:** After route calculates:
1. Tap "Export GPX" button
2. File saves to internal storage `/GPX/`
3. Open file manager, select GPX file
4. Choose OsmAnd or other navigation app

### Q: Can I use this offline?

**A:** No. Route calculation requires internet connection to BBBike API. Offline maps planned for v2+.

### Q: Does the app guarantee safe routes?

**A:** No. We provide routing data sourced from BBBike. Cyclists remain responsible for assessing local conditions before riding.

### Q: Which languages are supported?

**A:** v1 supports EN-AU, EN-GB, EN-US, DE, IT, ES, PT, FR, ZH. Additional languages depend on community contributions.

### Q: How do I become a beta tester?

**A:** Subscribe to Google Groups and respond to beta announcement posts.
